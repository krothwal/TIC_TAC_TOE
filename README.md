## 🎮 How to Play

1. Player X starts the game  
2. Click on any empty cell to place your mark  
3. Players take turns (X → O → X → O)  
4. First player to get:
   - 3 in a row (horizontal)
   - 3 in a column
   - 3 diagonally  
   wins the game 🎉  
5. If all cells are filled without a winner → it's a draw
